## Instruções de instalação
### Prebuilt
Baixe os binários em release, rode `earthRush.exe`

### Compilação
baixe o código fonte, navegue para a pasta TTEA, rode `uv run main.py`. Assim que aparecer o feed da câmera, é seguro fechar o terminal. 
Exporte pelo godot (feito na versão 4.7, verifique compatibilidade com versões futuras) e inclua a pasta TTEA junto do executável do jogo.
